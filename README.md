# Quill 原生微信小程序

在微信开发者工具中导入 **D:\Quill**。根目录 `app.json` 是页面入口，`miniprogramRoot` 为 `./`。修改 JS、WXML、WXSS 后直接在开发者工具编译，无需 npm 安装、uni-app、Vue 或先生成 dist。

## 配置

首次克隆仓库后，在项目目录执行 `npm run setup`（无需安装依赖），从示例生成本地配置，然后导入微信开发者工具。此命令不会覆盖已有配置。

仓库提交 `project.config.example.json` 和 `config/config.example.js`；实际使用的 `project.config.json`、`project.private.config.json`、`config/config.js` 以及 `.env` 文件均由 `.gitignore` 排除。AppID 是公开标识，但此项目统一将个人 AppID、接口地址和运营联系方式留在本地。AppSecret、Token 等密钥必须只保存在后端；Git 忽略不能阻止前端配置被打进小程序包。

- AppID：根目录 `project.config.json` 的 `appid`。将 `touristappid` 替换为自己的微信小程序 AppID。后端微信登录配置须使用同一个 AppID。AppSecret 只放后端。
- API 地址和环境隔离：`config/config.js` 的 `apiBaseUrl`、`environment`。
- 运营联系方式：`config/config.js` 的 `operatorContact`。
- 本机个性化开发设置：`project.private.config.json`，迁移时保留用户原文件。

调试基础库为 `3.17.2`。`project.private.config.json` 中的 `libVersion` 会覆盖项目配置，两处应保持一致。

当前兼容方案在 `app.json` 明确使用 `renderer: webview` 和 `componentFramework: exparser`，所有自定义组件在对应页面或组件的 JSON 中显式声明，不使用全局组件注册及 `lazyCodeLoading` 按需注入。工程只有 5 个页面和 5 个组件，采用启动时注入，避免继续依赖此前出现 `loadLibFiles`、`appLaunch timeout`、`navigateTo timeout` 的加载组合。此方案使用 3.17.2 基础库提供的传统组件框架，不要求降级基础库；它不能单独证明 glass-easel 存在缺陷。真实运行结果仍以模拟器和真机验收为准。

默认 API 为 `http://127.0.0.1:3210/v1`。微信开发者工具本地调试可关闭合法域名校验；真机须使用可访问的服务器地址，127.0.0.1 在手机上指手机自身。正式环境配置 HTTPS 请求域名及音频域名。

## 目录与 Hmall 的对应方式

```text
app.js / app.json / app.wxss   应用生命周期、页面注册、全局样式
config/                      环境和接口配置
pages/library/               内容库入口及类型筛选
pages/book/                  章节目录
pages/reader/                原文、搜索、逐句与整章播放
pages/settings/              微信登录、速度与进度管理
pages/privacy/               隐私说明
components/                  原生图标、底部弹层、播放器、冲突选择组件
models/                      内容、认证、播放器、进度等业务模块
core/                        独立的播放状态机与并发安全进度同步
utils/                       wx.request、存储、事件订阅、契约辅助函数
wxss/                        共用样式
imgs/                        本地图标
tests/ scripts/              Node 校验（不进入小程序包）
```

每个页面使用原生 `.js / .json / .wxml / .wxss`。业务模块使用微信支持的 CommonJS；页面只管理事件与展示，组件通过 properties / triggerEvent 通信。参考 Hmall 的组织方式，不引入商城业务、商城 AppID 或不需要的 UI 依赖。

## 功能与后端

保留内容库、分页、最近学习、章节目录、章内搜索、逐句/整章音频、四档倍速、循环/章内连播、后台暂停、微信登录、游客进度、云端版本冲突与清除确认。进入阅读页不自动播放，搜索保留原句编号，音频授权和进度 API 沿用原后端。

后端已独立迁移到 `D:\quill-backend`，在该目录执行 `npm.cmd run dev`，完整配置与启动说明见 `D:\quill-backend\README.md`。现有数据库、音频和签名密钥位于后端 `.data` 目录；本机 API 地址仍为 `http://127.0.0.1:3210/v1`。前端不内置虚假登录或伪造内容。云端登录需要后端真实微信配置。

`D:\Quill` 中的旧 `frontend/`（uni-app 源码及构建产物）和旧 `contracts/` 副本已清理，直接维护根目录原生工程。AppID 统一在根目录 `project.config.json` 配置。`.codex-tools/` 是已有的本地工具目录，不进入小程序包。

## 界面与原生样式

内容库、章节目录、逐句/全文播放器、我的与设置、登录、隐私说明及底部弹层使用统一的暖白与深绿样式。自定义导航按状态栏和微信胶囊位置留出安全区。

- 游客默认显示“体验样本”，登录后默认显示“我的内容”；没有最近学习记录时不展示继续学习卡片。内容、单元数、学习位置和全文音频可用状态均来自实际数据。
- 内容库支持下拉刷新和加载更多；内容点击进入目录，继续学习恢复阅读位置但不会自动播放。
- 所有自定义按钮显式声明 `size="default"`，共用样式及组件的 `button[size="default"].类名` 选择器覆盖微信 `style: v2` 的默认宽度和自动居中。新增按钮请沿用此约定，不能只在浏览器中验证布局。
- 所有封面固定宽高比例，长标题换行时不会拉长封面。阅读页监听网络状态，页面退出时清理监听。

已在微信开发者工具 2.02.2608070 / 基础库 3.17.2 的 iPhone 15 Pro Max 模拟器中验证书架、目录、逐句阅读、全文播放、登录页与隐私页。样本全文播放实际启动并计时；微信账号登录与 iOS/Android 真机表现仍需单独验收。
## 内容库入口（2026-09-20）

入口按确认的多内容设计改为“内容库 / 我的内容 / 最近学习”，使用“全部、书籍、博客、电影、电视剧”筛选、暖白背景、深绿继续学习按钮、统一缩略图与细分割线。刷新使用下拉手势，列表末尾只在仍有数据时显示“加载更多”。

现有 `/books` 路由、`bookId`、章节与播放/进度接口保持兼容。列表和详情可返回以下可选展示字段：

| 字段 | 约定 |
| --- | --- |
| `contentType` | `book`、`blog`、`movie`、`tv`；缺省按旧书籍处理，未知值显示其他内容，不推断标题类型 |
| `unitCount` | 可选非负整数；缺省使用 `chapterCount`。类型对应章、篇、段、集 |
| `coverUrl` | 可选 HTTPS 配图地址；应配置微信合法下载域名。加载失败恢复本地类型配图 |

博客、电影、电视剧的默认缩略图来自按设计稿生成的本地图片 `imgs/covers/content-types.jpg`（约 226 KiB），书籍默认显示动态文字封面。图片仅作类型缺省视觉，不代表新增了实际内容或播放权限。

分类基于服务端返回的真实 `contentType`，不会把现有书籍改名为电影或伪造四条示例。当前后端仍仅返回书籍时，其他分类正常显示空状态；发布多类型内容时需同步扩展后端导入与响应字段。全部类型继续使用原有文本/音频学习流程，不增加视频播放。

前端兼容现有混合分页：切换到未加载到的类型时继续扫描后续页，每次最多 5 页；仍有游标时提示继续加载，不把尚未遍历完的列表误报为空。切换分类或账号后，旧请求不能覆盖当前结果；刷新失败保留已加载条目。最近学习独立于分类筛选，恢复单元及句子位置但不自动播放。

设计中的示例内容、账号状态与进度只用于隔离的视觉验证，不内置到运行时数据。实际页面的样本标记、音频可用性、登录状态、空状态均按真实数据显示；系统状态栏和微信胶囊遵循设备安全区。

## 校验

安装 Node.js 18 或更高版本后执行 `npm run check`、`npm test`，无需安装依赖。check 检查所有页面四件套、JSON、JS 语法、模块引用和组件引用；test 验证播放取消、音频不可用、并发同步与页面生命周期。

后端运行时可执行 `node scripts/smoke-api.cjs` 检查公开书籍、正文和音频授权接口。

真实微信音频表现、微信登录和发布预览还需在开发者工具/真机中验收。
